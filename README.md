# Compiti
In-browser, local task manager with some Kanban features.

https://bitmochibit.github.io/compiti/

It works with Wallpaper Engine (or any of this kind of softwares that support a webview, like lively wallpaper)

Extremely useful to someone that forgets that Trello or Clickup exists and want to have all task sorted out as a desktop widget.


## Plans for this app
It's a prototype, and I will add some other features when I need them, and probably migrate to a better framework, since I don't really like vanilla javascript.
